# 오늘 코디

날씨와 내 옷장으로 오늘(저녁엔 내일) 입을 옷을 골라 주는 개인용 웹앱.

- 주소: https://jihooni217.github.io/codi/
- 아이폰 설치: Safari로 열기 → 공유 → 홈 화면에 추가
- 배포: `main`에 올리면 GitHub Pages(루트)가 바로 반영 (1~2분)

## 구조

- `index.html` 파일 하나에 화면·계산이 다 있다 (빌드 없음, 그냥 HTML/JS)
- `icon-180/192/512.png`: 앱 아이콘
- 저장은 폰 브라우저 localStorage에만 한다. 서버 없음
  - `codi_wardrobe_v1`: 옷장
  - `codi_body_v1`: 신체 치수와 원하는 핏 (코드 기본값은 비어 있음. 치수는 저장소에 올리지 않는다)
- 폰을 바꾸기 전에 **옷장 탭 → 백업**으로 파일을 받아 두고, 새 폰에서 불러온다 (옷장 + 신체 치수)
- 날씨: Open-Meteo (현재값 + 오늘·내일 최저/최고/강수/날씨 코드). 위치 권한이 없으면 서울. 앱을 다시 열었을 때 10분이 지났으면 새로 받는다

## 화면

탭 3개: 오늘 · 옷장 · 쇼핑

- **오늘**: 열자마자 한 벌만 크게 보여 준다(아우터·상의·이너·하의·신발 + 안내 한 줄). "다른 조합 보기"로 01→04, 다 보면 새 조합. 18시 이후에 열면 내일 것을 보여 준다. 하의·온도·오늘/내일 직접 고르기는 아래에서 올라오는 창
- **옷장**: 옷 추가·삭제, 백업·불러오기
- **쇼핑**: 사려는 옷의 색 확인(캡처를 올리거나 색 이름 입력 → 어울림 판단), 핏 확인(실측 사이즈표 숫자 입력 → 내 치수와 비교)

## 추천 규칙

- 기준 온도 = 그날 최저·최고의 중간값 (체감온도는 쓰지 않는다). 일교차 10° 이상이면 "겉옷 챙기기" 표시
- 단계: 더움 23↑ / 선선 17~22 / 쌀쌀 11~16 / 추움 5~10 / 한파 5 아래
- 퍼스널 컬러 **여름 쿨 뮤트**. 색마다 g(잘 맞음) / o(괜찮음) / a(얼굴 근처는 피함). a색 상의는 이너를 받쳐 목에 보이게
- 아우터 종류: 1 가벼움 · 2 중간 · 2w 충전재(추움에만) · 3 두꺼움
- 하의 종류: pants · thick(더움 제외) · shorts(더움에만)
- 추천은 날짜가 섞인 난수라 날마다 바뀌고, 같은 날에는 밤에 본 1번이 아침에도 1번 (날씨 단계가 그대로면)
- 신발
  - 비 오면 캔버스화(제이다울) 빼기, 한파에도 빼기
  - `NOPAIR`: 옐로우 더스트 인디고 데님 + NB 480 베이지는 짝짓지 않음 (밑단이 신발 혀에 걸림)
- 그레이 스웨트 팬츠는 옆 단추로 조거·커브드·와이드가 된다 → 후드·맨투맨과는 "밑단은 조거나 커브드로", 그 밖엔 "펴서 와이드로" 안내

## 스타일 선호

- 상의: 세미 오버핏 기본, 지나치게 부풀어 보이는 건 피함
- 하의: 세미 와이드 또는 세미 커브드
- 긴바지는 신발을 덮는 기장이 어울림
- 큰 상의 + 정돈된 일자 바지 / 몸에 맞는 상의 + 넉넉한 바지 로 균형

## 옷장 메모

- 이름은 모델명 위주: 카키모카 니트, 제이다울 아이보리, 셀비지 카펜터 와이드 데님(예전 "생지 데님"), 블랙 나일론 투턱 테이핑 팬츠(예전 "블랙 트랙 팬츠"와 같은 옷이라 합침)
- 그레이 스웨트 팬츠는 실제로 하나 더 있지만 앱엔 하나만 둔다
- LMS 후디(그레이·네이비)는 사이즈가 커서(드롭숄더가 많이 내려옴, 모자가 처짐) 잘 안 입는다. 어울리는 하의는 셀비지 카펜터, 나일론 투턱은 위아래가 다 커서 안 맞음 (추천 규칙에는 아직 안 넣음)
- 블랙 스웨트 팬츠는 밑위가 깊고 아래로 좁아지는 모양, 나일론 투턱은 넓은 일자, 카펜터는 허벅지가 정돈된 일자
- 핏 확인의 허리 판정은 브랜드마다 재는 법이 달라 참고만 한다 (고무줄 허리는 무시)
